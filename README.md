# AK-Swift ⌨️

A typing speed test app I built while learning React.

---

## The Story

I wanted to get faster at typing, so instead of just using other tools online, I decided to build my own. It was a great way to practice React while also making something I actually use every day.

---

## What It Does

- **Timed Mode** — You get 60 seconds to type as much as you can. Good for speed practice.
- **Passage Mode** — No time limit. The timer counts up so you can see how long you took to finish the full text.
- **Three Difficulty Levels** — Easy, Medium, and Hard texts to match where you are.
- **Live WPM & Accuracy** — See your words per minute and accuracy update as you type.
- **Color Feedback** — Correct letters turn green, wrong ones turn red. Instant and clear.
- **Personal Best** — Your best score is saved so you can track your progress over time.

---

## Built With

- **React** — for building the UI and managing state
- **CSS** — for styling

---

## The Goal

The goal is simple: have a clean, distraction-free tool to practice typing every day and actually get better.
